# Информационная система малого предприятия связи «СвязьТелеком»

Демонстрационный прототип информационной системы (ИС) для малого оператора связи.
Проект выполнен как практическая часть курсовой работы по теме
**«Проектирование информационной системы для малого предприятия связи»**.

## Как запустить

Ничего устанавливать не нужно:

1. Откройте файл `index.html` двойным щелчком в браузере (Chrome, Edge, Firefox).
2. Готово — сайт и все подсистемы работают локально.

> Альтернативно: в VS Code нажать «Go Live» (расширение Live Server) или выполнить
> `python -m http.server` в папке проекта и открыть `http://localhost:8000`.

## Что реализовано

**Публичная часть**
- Главная страница, услуги, тарифы, о компании, контакты.
- Заявка на подключение → автоматически попадает в базу заявок ИС.
- Форма обратной связи → попадает в базу обращений.

**Личный кабинет абонента**
- Просмотр тарифа, баланса, истории платежей.
- Пополнение лицевого счёта (создаёт запись платежа).
- Смена тарифного плана.
- Обращения в поддержку с отслеживанием статуса.
- Редактирование контактных данных.

**Панель управления (АРМ оператора/администратора)**
- Дашборд с ключевыми показателями и диаграммами.
- Обработка заявок (статус, исполнитель, сроки).
- Ведение карточек абонентов (CRUD), блокировка.
- Обработка обращений и ответы абонентам.
- Управление тарифами, учёт склада, сотрудники и роли.
- Отчёты и экспорт на печать (PDF).

## Технологии

- **HTML5, CSS3** (Grid, Flexbox, CSS-переменные, тёмная тема).
- **JavaScript ES6+** без сторонних библиотек.
- **Хранилище:** `localStorage` — имитация СУБД для работы без сервера.
  В промышленной версии слой `Store` заменяется вызовами REST API над PostgreSQL.

## Сброс демонстрационных данных

В личном кабинете или панели управления есть кнопка **«Сбросить демо-данные»** —
она возвращает базу к исходному состоянию. Также можно очистить данные браузера
(DevTools → Application → Local Storage).
